Four years of burning itself for breakfast on dial 3, called "the thing", crumb tray never once emptied — so the toaster is not broken, it is leaving, and the owner can keep the crumbs.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```

This writes the line to `output/entry.txt`.
